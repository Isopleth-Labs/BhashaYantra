# BhashaYantra Support

## Beta support

- Bugs and feature feedback: [GitHub Issues](https://github.com/Isopleth-Labs/BhashaYantra/issues)
- Product and setup documentation: [`docs/`](docs/00-documentation-index.md)
- Security vulnerabilities: use [private vulnerability reporting](https://github.com/Isopleth-Labs/BhashaYantra/security/advisories) and follow [`SECURITY.md`](SECURITY.md). Do not publish exploit details or credentials.

Include the app version, Windows version, selected language/layout, expected behavior, actual behavior, and minimal reproduction steps. Remove private documents, personal information, passwords, access tokens, Supabase keys, and database credentials before attaching logs or screenshots.

Production support, privacy, billing, and account-recovery email addresses are not active yet. They are public-beta release gates, not hidden working channels.
